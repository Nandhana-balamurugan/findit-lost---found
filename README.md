# 🔎 FindIt - Campus Lost & Found Platform

FindIt is a modern web application that helps students report lost items, share found belongings, and reconnect items with their owners across campus.

## 🚀 Features
* **Report Lost & Found Items:** Quickly post items with location, category, contact details, and optional photo uploads.
* **Search & Filter:** Instantly filter items by category, type (Lost vs. Found), or search keywords.
* **Status Updates:** Mark items as resolved once they are returned to their owners.
* **Authentication:** Secure user accounts powered by Supabase Auth.
* **Responsive Design:** Optimized for both mobile devices and desktop screens.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, CSS3
* **Backend & Database:** Supabase (PostgreSQL, Auth, Storage)
* **Deployment:** Vercel
